# آموزش میکروکنترلر — نسخهٔ فارسی

۱۶ درس تعاملی و سه‌بعدی میکروکنترلر برای مبتدی‌ها، کاملاً فارسی.
برد میکروکنترلر را روی صفحه می‌بینید، قطعه‌ها را می‌شناسید، کد را اجرا می‌کنید و نتیجه‌اش را روی برد می‌بینید؛ بدون نیاز به برد واقعی.

مناسب دانشجویان و اساتید دانشگاه آزاد برای کلاس، تمرین و مرور درس.

طراحی، ساخت و ترجمهٔ فارسی: [آراد آذرپناه](https://aradazr.site)

## نسخهٔ آنلاین (بدون نصب)

👈 **[aradazr.github.io/learn-microcontroller](https://aradazr.github.io/learn-microcontroller/)**

فقط لینک را در مرورگر باز کنید. اگر اینترنت ندارید یا می‌خواهید روی کامپیوتر خودتان اجرا شود، مراحل زیر را بروید.

---

## ۱. دانلود

بالای همین صفحه روی دکمهٔ سبز **Code** بزنید و **Download ZIP** را انتخاب کنید.
فایل را از حالت فشرده خارج کنید (Extract).

## ۲. نصب پایتون (فقط یک بار)

برای باز شدن سایت روی کامپیوتر به **Python** نیاز است.

- **ویندوز:** از [python.org/downloads](https://www.python.org/downloads/) دانلود و نصب کنید.
  موقع نصب، تیک **Add python.exe to PATH** را حتماً بزنید.
- **مک:** معمولاً از قبل نصب است.

## ۳. اجرا

- **ویندوز:** روی فایل `start-windows.bat` دوبار کلیک کنید.
- **مک:** روی فایل `start-mac.command` راست‌کلیک کنید و **Open** را بزنید.

مرورگر خودش باز می‌شود. اگر باز نشد، این آدرس را در مرورگر بزنید:

```
http://localhost:8090/fa/
```

تا وقتی با سایت کار می‌کنید، پنجرهٔ سیاه (ترمینال) را **نبندید**. برای خاموش کردن، همان پنجره را ببندید.

> بهترین مرورگر: Chrome یا Edge (سایت سه‌بعدی است و به WebGL نیاز دارد).

---

## کار با سایت

- **انتخاب درس:** نوار **درس‌ها** پایین صفحه. از درس ۱ شروع کنید و به ترتیب جلو بروید.
- **حرکت روی برد:** با ماوس بکشید یا از کلیدهای `W` `A` `S` `D` استفاده کنید.
  چرخش با `Q` و `E`، بزرگ‌نمایی با اسکرول ماوس.
- **شناختن قطعه‌ها:** روی هر قطعه کلیک کنید تا توضیحش باز شود.
- **توضیح درس:** پنل سمت راست؛ زبانه‌های **مرور کلی**، **نقشهٔ پایه‌ها** و **مثال**.
- **اجرای کد:** در بخش **خودتان امتحان کنید** دکمهٔ اجرا را بزنید و نتیجه را روی برد ببینید.
- **تنظیمات:** آیکون چرخ‌دنده در نوار کناری (زبان، صدا، برچسب‌ها و …).

## پیشنهاد برای اساتید

- سایت را روی ویدئوپروژکتور باز کنید و هر جلسه یک یا دو درس را با هم جلو بروید.
- کد هر درس را بعد از توضیح، روی برد واقعی هم اجرا کنید تا دانشجوها تفاوت شبیه‌سازی و واقعیت را ببینند.
- درس آخر (**ساخت یک پروژه**) برای پروژهٔ پایان ترم مناسب است.

## برای توسعه‌دهنده‌ها

اجرای دستی:

```bash
python3 -m http.server 8090 -d site
```

ساختار:

- `site/` — فایل‌های سایت (همان فایل‌های نسخهٔ منتشرشده، به‌علاوهٔ فارسی)
  - `site/fa/index.html` — صفحهٔ فارسی (`lang="fa" dir="rtl"`)
  - `site/assets/fa.js` — ترجمه‌ها (ساخته‌شده از `i18n/fa.json`)
  - `site/assets/fa-rtl.css` — فونت پیدا (`site/assets/fonts/`) و اصلاحات راست‌به‌چپ؛ کدها چپ‌به‌راست می‌مانند
- `i18n/fa.json` — همهٔ ۹۰۶ متن: انگلیسی ← فارسی. برای اصلاح ترجمه این فایل را ویرایش کنید.
- `tools/make-fa.mjs` — بعد از هر تغییر در ترجمه یا CSS اجرا شود:

```bash
node tools/make-fa.mjs
```

انتشار روی GitHub Pages خودکار است: با هر push روی `main`، فایل `.github/workflows/pages.yml`
اسکریپت `tools/make-pages.mjs` را اجرا می‌کند تا آدرس‌ها زیر مسیر `/learn-microcontroller/` درست کار کنند.
